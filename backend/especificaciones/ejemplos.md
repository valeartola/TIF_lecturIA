# Ejemplos calibrados — LecturIA

Este documento contiene ejemplos completos de preguntas evaluadas, para anclar
el criterio del juez en casos concretos. Cada ejemplo incluye texto fuente,
pregunta generada, scores asignados y justificación.

> **Estado:** vacío. Se llenará a medida que tengamos preguntas reales del
> generador, calibradas manualmente con la directora docente.

> **Cómo se usa:** se inyecta en el prompt del juez como referencia. Funciona
> como *few-shot prompting*: ver ejemplos calibrados ayuda al juez a aplicar
> la rúbrica de forma más consistente.

---

## Plantilla para nuevos ejemplos

Cuando se agreguen ejemplos, deben seguir esta estructura:

### Ejemplo N — [tipo textual] / [nivel] / [tipo de pregunta]

**Texto:**
> Fragmento del texto fuente.

**Pregunta generada:**
> ¿Pregunta?
>
> a) opción 1
> b) opción 2 ✓ (marcada como correcta)
> c) opción 3
> d) opción 4

**Evaluación:**
- D1 Anclaje: X/5
- D2 Corrección: X/5
- D3 Distractores: X/5
- D4 Nivel: X/5
- Aprobada: sí / no

**Justificación:**
Explicación breve de por qué se asignó cada puntaje, especialmente los más
bajos.
